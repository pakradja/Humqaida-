# Human recording workflow

No unlicensed, unreviewed, or synthetic recordings are bundled. Use **Parent → Teacher Audio Studio** to record or choose files, privately upload them to Supabase, and approve a specific version after listening.

The database and app use collision-safe IDs such as `letter_ha_emphatic`, `letter_ha`, `letter_ta_emphatic`, and `letter_ta`. Files live in the private `qaida-audio` bucket under `<learner-id>/<content-id>/<random-id>.<format>`. Do not add pronunciation files to this public web directory.

Record in a quiet room, use a short silence at each end, and test the result on Humza’s actual iPad. The first release treats the Wikimedia candidate and teacher clips as letter names only—not makharij certification or vowel/Quranic-word audio.

## Consent and license record

The upload form records the speaker’s permission confirmation. Keep any separate signed note with the family’s private records. Do not publish third-party recordings without an explicit redistribution license.
